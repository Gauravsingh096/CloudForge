# dashboard

React (Vite) frontend — developer UI for CloudForge. Deployed on Vercel free tier.

## Features (planned)

- GitHub OAuth login
- Project list and create
- Deploy history with status and logs
- Real-time pod logs (tail)
- Grafana embed for per-app metrics
- Self-healing audit log view
- Pause/resume auto-heal toggle
